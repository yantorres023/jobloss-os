# GROWTH & DISTRIBUTION — JobLoss OS

**No outreach was done.** These are plans.

## Moments that matter
The user needs this in the first 72 hours after a layoff. Distribution must be **at the layoff moment**, not via app-store search.

| Channel | Moment | Mechanism | Notes |
|---|---|---|---|
| Employer layoff packet / outplacement kickoff | Day 0 | QR code on a one-page handout; landing page | Sponsor model #1 |
| WARN-notice layoffs (TWC publishes WARN data, S17) | Days −60 to 0 | Future partner outreach to employers/outplacement on public WARN lists | Do not scrape or contact workers directly |
| Legal-aid & Texas Law Help referrals | Denial/appeal | Link from resource pages; export helps intake | Must be clearly unofficial |
| Credit unions / unions | Hardship calls | Member newsletters | |
| Workforce Solutions offices (Rapid Response, S16) | Orientation sessions | Only if a board chooses to list it; **never implied endorsement** | Future |
| SEO landing page | Search for "TWC appeal deadline", "TWC work search log" | Plain page linking to TWC, with app download | Competes with content farms (S61, S67) |

## Landing page
`landing/index.html` — static, no trackers, states "not TWC" in the first screen, links to official TWC pages.

## Metrics (beta, survey-based)
Activation: onboarding completed + ≥1 letter or filing date entered within 7 days.
Value: ≥1 proof saved per payment-request cycle.
Referral: % of beta users who shared the app with another laid-off person (self-report).

## Anti-growth rules
No ads, no referral bonuses, no push re-engagement unrelated to a user's own deadlines, no dark patterns in a crisis moment.
